# Code of Conduct

## Our Standard

PyRoboSimulator is currently maintained by a single person
([@Mullassery](https://github.com/Mullassery)). There is no formal
enforcement team. This document sets expectations, not a bureaucracy.

Participants in this project's issues, pull requests, and discussions are
expected to:

- Be respectful and constructive in disagreement.
- Focus criticism on code and ideas, not people.
- Accept that maintainer time is limited and volunteer-based; a slow or "no"
  response is not an invitation to escalate.
- Not post harassment, personal attacks, discriminatory language, or spam.

## Scope

This applies to project spaces: GitHub issues, pull requests, discussions,
and any other official communication channel for this repository.

## Enforcement

Reports of unacceptable behavior can be made to the maintainer at
mullassery@gmail.com. Given the single-maintainer reality above, there is
no guaranteed response time and no separate enforcement body to escalate
to — the maintainer will use their judgment, up to and including blocking
a user from the repository.

## Attribution

This is a short, honest version of the intent behind the
[Contributor Covenant](https://www.contributor-covenant.org/), adapted to
reflect this project's actual (solo) maintenance capacity rather than
claiming an enforcement process that does not exist.
